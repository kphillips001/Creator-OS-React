CORE USER DESIGN

PURPOSE

The architecture has been rebased.

Telegram is now the primary conversational channel.

Fanvue is a commerce provider.

DropFans may become a commerce provider.

KVIQA may become the CRM and/or vault provider.

The system must no longer depend on Fanvue users as the canonical identity.

The purpose of this task is to design the platform-neutral core user model.

This is a planning task only.

--------------------------------------------------
OBJECTIVE
--------------------------------------------------

Define the future identity architecture.

The design must support:

- Telegram-first users
- Users with no Fanvue account
- Users with no DropFans account
- Users with no KVIQA record
- Multiple future commerce providers
- Multiple future communication channels

without changing intelligence ownership.
