IMPORTANT:

The migration will use a unified identity model.

DO NOT create Telegram-only users.

DO NOT create separate memory systems.

DO NOT create separate buyer intelligence systems.

Required model:

Telegram User
↓
Internal User
↓
Fanvue Commerce Identity

All intelligence must remain attached to the Internal User.
