IDENTITY FOUNDATION ALIGNMENT

PURPOSE

The database readiness audit determined that the Telegram Identity Foundation architecture is correct, but several implementation details must be aligned with the actual PostgreSQL schema before integration work begins.

This task exists to harden the identity foundation and validate it against a disposable PostgreSQL restore.

---

## OBJECTIVE

Revise the Telegram Identity Foundation so it matches the actual FanvueChatbot database schema.

Do not implement Telegram transport.

Do not modify DecisionEngine.

Do not modify Memory.

Do not modify Buyer Intelligence.
