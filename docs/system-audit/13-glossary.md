# Glossary

- **Canonical reference:** protected, creator-scoped identity image used to preserve who is depicted.
- **Continuity reference:** latest approved photoshoot image used to preserve the current session’s styling/scene; not the canonical identity record.
- **Generation:** provider output and metadata before canonical registration.
- **Staged asset:** generation or typed deliverable placed in Asset Library awaiting registration.
- **Registered asset:** canonical Asset record linked to source/provenance and analysis workflow.
- **READY:** all required intelligence stages completed; not synonymous with available, offered, or published.
- **Content Intelligence:** merged structured description, safety, semantic and commercial suitability profile.
- **Content Destination:** the one authoritative permanent commercial assignment for an Asset.
- **Available Inventory:** READY canonical content whose destination is AVAILABLE_INVENTORY and which is eligible for assignment.
- **In service:** commerce availability/operational state; separate from destination.
- **Offering:** creator-defined commercial package of one or more Assets, price, currency and primary sales channel.
- **Publication:** provider-specific publishable record for an Offering; for Fanvue it tracks Media Link execution.
- **Photoshoot seed:** first image/Shot 1 from which a session begins.
- **Photoset:** immutable curated multi-image commercial assignment.
- **Teaser:** committed promotional content, not the paid offering itself.
- **PPV:** pay-per-view offer/delivery; single chat/wall uses are distinct business commitments.
- **AI Chat:** offering’s direct conversational sales channel.
- **Telegram Wall/Content Vault:** channel publication presenting an Offering and authoritative unlock link; distinct from Generation Library Broadcast.
- **Purchase Intent:** immutable history of an offering presented to a buyer, with active/expired/purchased/unknown lifecycle.
- **Customer Commerce Profile:** per creator/Fanvue-buyer aggregate derived from verified transactions.
- **Observe mode:** evaluate and record decisions without external sends.
- **Live mode:** permits external action only if every additional safety/configuration gate passes.
- **Deployment readiness:** evidence that runtime, config, identity, data and workers can execute; not an operator toggle.
- **Worker lease:** time-bounded exclusive claim on a queued job.
- **Commercial publication:** provider-neutral Offering publication record; not the social publication history.
- **Canonical conversation brain:** ConversationGateway + Sales Brain + selector + DecisionEngine/GPT composition shared by Telegram and Test Chat.
